Research profile

Roboticist specialising in event-based vision, robotic localisation, and open-source research software. Research Fellow at the QUT Centre for Robotics, working on vision-based positioning for Roo-ver, Australia’s first lunar rover. Developer of EventCV, with research spanning embedded neuromorphic localisation, event-based place recognition, and reproducible evaluation workflows.

Open-source software

EventCV

Developer of an open-source event-based computer vision library with a Python interface and Rust core. Work spans recording formats and live cameras, event representations, feature detection, motion estimation, simulation, reconstruction, visualisation, documentation, and developer tooling.
